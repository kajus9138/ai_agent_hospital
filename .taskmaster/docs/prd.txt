# PRD - ai_agent_hospital
## 1. Contexto
Este projeto será apresentado como uma POC para demonstrar o funcionamento de um agente ReAct no contexto hospitalar.
Nesta primeira etapa ele se conectará a um MCP local através de std. O llm utilizado pelo agente também é local e deve
ser hospedado no Ollama.
## 2. Objetivo
Um agente ReAct com llm local que se conecta a um MCP local por std.
## 3. Usuário-alvo
Tratando-se de uma POC, o cenário criado é de um tomador de decisão em um hospital inteligente.
Inclua cenários reais quando possível.>
## 4. Escopo (nesta versão)
- Interação com o usuário
- Threads armazenadas em Postgrees
- Comunicação com o MCP local que traz dados sobre a dengue em São Paulo


## 5. Arquitetura inicial
Python 3.12
Langgraph
Postgrees
## 6. Critérios de aceite
- O sistema DEVE comunicar-se com o MCP local
- A documentação DEVE estar informativa e organizada
